# Проект 58: планы и их обсуждение

Репозиторий для менторов «Проекта 58» (9 класс, 2026–2027): здесь лежат планы курса, саммари встреч команды и идёт их обсуждение.

Код, лабораторные, контесты и материалы уроков — в репозитории курса: https://github.com/TIlzziter/p58-course-2026. Здесь только тексты планов, код не дублируется.

## Структура

- `plans/current-annual-plan.md` — текущий годовой план (копия текста из README курса, до изменений 27.10).
- `plans/2026-10-27-plan-update.md` — предложения по обновлению плана после встречи 27.10 (не утверждены, согласование к 30.10).
- `meetings/2026-10-27-summary.md` — саммари встречи 27.10 (автоматическое саммари Zoom, машинный перевод).

## Как обсуждать

- **Один открытый вопрос — одно Issue** с меткой «открытый вопрос». Пишите в комментариях мнения, аргументы и альтернативы; когда решили — фиксируем решение в последнем комментарии и закрываем Issue.
- **Правки текста плана — через Pull Request**: ветка → изменения → PR со ссылкой на Issue, которое он закрывает. Мелкие правки можно предлагать прямо в комментариях к PR.
- Общие темы, не привязанные к конкретному вопросу, — в Discussions.
- Репозиторий публичный: не пишите сюда фамилии и оценки учеников, контакты, токены и пароли.
